# MobileVueAssistant

This custom agent is designed for the **Glow Skincare** Vue.js project. Use it whenever you need to:
- Implement mobile‑friendly UI changes.
- Optimize components for small screens.
- Adjust styling, layout, or routing for responsive behavior.
- Run build or lint commands related to mobile work.

The agent has full access to the project files and can execute terminal commands as needed.

**Example prompts**:
- "Make the product cards responsive for mobile screens."
- "Add a hamburger menu to the header for mobile navigation."
- "Run the build and check for any mobile‑specific lint warnings."
